# CO₂/N₂ MOF selectivity — revised numerical results and figure sources

This `revision` branch is the numerical/plotting handoff for the corrected JCTC study. It is deliberately **not** the manuscript source. The revised article and Supporting Information are maintained in the separately shared Overleaf package. Do not treat old data under `data/authoritative/` or the historical plotting entrypoint as corrected publication figures.

## Coauthor quick start

```powershell
python -m pip install -r requirements_figures.txt
python scripts/plot_revision_all.py
```

The command recreates the six article figures, four SI figures (S2 is retained unchanged), and the TOC from tracked numerical sources without running RASPA or refitting ML. Editable plotting logic is in `scripts/plot_revision_main.py` and `scripts/plot_revision_si.py`. Publication PDFs are under `figures/main/`, `figures/si/`, and `figures/toc/`; raster exports and standalone panel crops are regenerated by the command rather than tracked here.

- Population source: `data/revision/corrected_wca_238.csv` (238 MOFs; corrected WCA and attraction, unchanged archived LJ/full/electrostatic endpoints).
- Geometry ML values used in Fig. 3: `data/revision/geometry_cv_metrics_for_fig3.csv` (five random folds; *not* topology transfer).
- Figure 4(b) original-cohort gas increments: `data/revision/matched_pair_gas_increments.csv`.
- `data/revision/figure_baselines.zip` contains published-layout legacy canvases used only to retain approved and unaffected panels, **not** authoritative revised science data.
- The former `scripts/regenerate_figures.py` is a historical pipeline and should not be used for the revised article.

Numerical QA: `quality_control/revision_figure_checks.json`. Full workflow and caveats: [docs/REVISED_FIGURE_WORKFLOW.md](docs/REVISED_FIGURE_WORKFLOW.md).

## Preserving provenance

Original simulation archives are unchanged. Original WCA output is scientifically superseded by validated cumulative isotropic-sampling corrections; it remains available for historical traceability. The charged full/LJ baseline was not rerun for the population. Fixed 8-/6-framework sensitivity results are distinct from the 238-framework population and do not imply force-field-invariant rankings. No manuscript or SI LaTeX is maintained on this branch.
